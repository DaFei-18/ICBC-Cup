# 《E心助贷》—— 面向电商小微企业的大数据智能风控与融资服务平台

本项目是一个面向电商小微企业的大数据智能风控与融资服务平台，为“工行杯”全国大学生金融科技创新大赛参赛项目。系统旨在利用电商真实经营流水数据替代传统抵押物，为普惠金融信贷评估提供科学、透明、可解释的数字化风控解决方案。

## 🏗️ 系统总体架构

项目严格遵循“数据层 — 特征层 — 模型层 — 应用层”四层解耦架构设计：
* **数据层 (Data Layer)**：接入电商商户全生命周期流水（订单时序、退款纠纷、履约物流等），结合潜变量模型生成仿真高对抗性数据集。
* **特征层 (Feature Layer)**：重构传统 5C 模型为经营稳定性、交易质量、规模成长、客户结构、资金合规五大维度共 18 项核心指标，全面采用 Pandas 向量化引擎加速运算。
* **模型层 (Model Layer)**：构建“主评分卡 + 参考树模型”双模型对照体系，集成前置防刷单规则过滤与 IV 动态特征筛选机制。
* **应用层 (Application Layer)**：封装标准统一的多层路由评估工具包 (CreditToolkit)，集成大语言模型 (LLM) 智能风控诊断与 Streamlit 交互看板。

## ✨ 核心技术亮点

1. **三层动态模型路由机制 (L1/L2/L3)**：
   自适应商户数据授权深度与完整度。支持仅凭 6 项基础流水的 **L1 极简准入版**（白户秒批）、12 项特征的 **L2 标准经营版**，以及五维全量的 **L3 全维增信版**，实现平滑降级与差异化授信。
2. **监管级白盒评分卡与刻度推导**：
   主模型基于 WOE 等频分箱 + 逻辑回归构建。引入 **Laplace (+0.5) 平滑**消除零频除零异常；严格对齐行业标准刻度推导公式 $Score = A + B \times \ln(Odds)$（基准好坏比 20:1 对应 600 分，PDO=20 分），支持单特征正负分值精准线性拆解。
3. **IV 值动态特征筛选机制**：
   在模型训练流程中引入自动化弱特征剔除机制，动态过滤 $IV < 0.02$ 的无区分能力指标，并提供 `dropped_features_report()` 导出被剔除特征清单，确保入模指标高效纯净。
4. **双模型对照与 SHAP 归因印证**：
   引入 LightGBM 梯度提升树模型作为非线性预测精度基线 (AUC 达到 0.83 左右)，并运用博弈论 TreeSHAP 计算特征边际贡献，与主评分卡形成互补印证。
5. **前置防刷单规则引擎**：
   在特征入模前设立时间集中度 (>35%)、客户重复度 (>50%)、物流缺失率 (>15%) 三重拦截卡口，前置阻断黑产作弊流水。
6. **AI 智能风控报告与容灾降级 (Fallback)**：
   打通大语言模型（兼容 Gemini、通义千问等主流大模型 API），将枯燥的评分卡拆解转换为 150 字以内专业诊断报告；内置离线规则模板降级机制，断网状态下系统仍 100% 高可用。
