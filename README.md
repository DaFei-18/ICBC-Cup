# 《E心助贷》—— 面向电商小微企业的大数据智能风控与融资服务平台[cite: 1]

本项目是一个面向电商小微企业的大数据智能风控与融资服务平台，是“工行杯”的参赛项目[cite: 1]。系统旨在利用电商数据替代传统抵押物，为金融风控和信贷评估提供科学、可靠的数字化解决方案[cite: 1]。

## 🏗️ 系统架构

本项目采用了清晰的“数据层—特征层—模型层—应用层”四层架构[cite: 1]：
* **数据层**：负责获取和存储电商经营数据[cite: 1]。
* **特征层**：对原始数据进行加工，提炼出核心风控特征[cite: 1]。
* **模型层**：系统的核心大脑，包含主模型、参考模型及异常检测引擎[cite: 1]。
* **应用层**：将模型能力封装为标准化的工具包和可视化看板，直接服务于终端用户[cite: 1]。

## ✨ 核心技术亮点

* **双模型对照体系**：主模型采用逻辑回归+WOE分箱的评分卡模型，满足金融监管对“可解释性”的刚性要求；参考模型采用LightGBM+SHAP验证预测精度并输出非线性风险归因[cite: 1]。
* **三层模型路由机制**：系统能够根据商户数据完整度，自动适配 L1（极简准入版）、L2（标准经营版）、L3（全维增信版）的动态模型路由体系[cite: 1]。
* **五大维度特征工程**：提炼涵盖经营稳定性、交易质量、规模与成长性、客户结构、资金流与合规五大类共约18项核心指标，完成传统5C模型的电商数字化重构[cite: 1]。
* **防刷单规则引擎**：轻量级前置规则引擎，用于识别时间集中度异常、客户重复度异常等，防范电商“刷单造假”的现实风险[cite: 1]。
* **统一多层路由风控评估引擎**：将底层的特征处理、评分卡模型和解释逻辑封装为标准化的 CreditToolkit 工具包，对外提供统一的输入输出接口，实现“即插即用”[cite: 1]。
* **可视化看板**：基于 Streamlit 构建前端交互看板，直观展示店铺的五维经营画像雷达图、信用评分等级，以及基于SHAP值的风险归因排行（展示影响评分的Top5因素）[cite: 1, 2]。
* **AI 智能风控诊断**：集成大语言模型，将枯燥的评分卡分值拆解自动翻译成面向信贷经理与商户的自然语言风控诊断报告[cite: 1]。

## 📂 项目目录结构

* `data/`：包含模拟生成电商小微企业的数据脚本[cite: 1]。
* `src/features/`：负责执行数据预处理与特征工程计算[cite: 1]。
* `src/models/`：包含评分卡主模型、LightGBM参考模型，以及负责计算AUC、KS、PSI等指标的模型评估脚本[cite: 1]。
* `src/rules/`：包含前置的异常交易与防刷单检测模块[cite: 1]。
* `src/llm/`：基于大语言模型的 AI 风控诊断报告生成模块[cite: 1]。
* `src/toolkit/`：统一 API 接口封装，实现评估引擎的对外服务[cite: 1]。
* `dashboard/`：基于 Streamlit 和 Plotly 搭建的可视化看板应用代码[cite: 1]。
* `tests/`：包含端到端测试流水线脚本，确保全链路跑通[cite: 1]。
