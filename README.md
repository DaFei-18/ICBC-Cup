## ✨ 核心技术与业务亮点

1. **工业级异构数据清洗网关 (`ECommerceDataCleaner`)**：
内置跨平台别名词典与正则清洗管道，支持抹平国内外不同电商平台（如 Olist 真实拉美流水、天池电商数据）在字段命名、货币符号（$、¥）及时间格式上的差异，实现外部数据“即插即洗、即插即测”。
2. **三层动态模型路由体系 (L1 / L2 / L3)**：
自动识别商户数据授权深度与字段完整度。具备缺失字段容错机制，支持轻量流水的 **L1 极简准入版**（6项核心特征，白户秒批）、**L2 标准经营版**（12项特征）与 **L3 全维增信版**（18项全量特征），实现平滑降级与差异化授信决策。


3. **监管级白盒评分卡与分值线性拆解**：
主模型基于 WOE 分箱与逻辑回归，引入 **Laplace (+0.5) 平滑**消除极端零频；对齐标准金融刻度公式：



$$Score = A + B \times \ln(Odds)$$



（基准好坏比 20:1 对应 600 分，PDO=20 分），严格支持单项特征“正向加分 / 负向扣分”的透明归因。


4. **IV 值动态筛选与双模型对抗校验**：
训练中自动化剔除 $IV < 0.02$ 的弱预测指标；引入 LightGBM 梯度提升树模型（AUC 达 0.83 左右）作为非线性基准，并运用 TreeSHAP 边际贡献度与主评分卡线性拆解交叉印证。


5. **前置防刷单风险拦截引擎**：
在特征入模前设立时间集中度、买家集中度及物流缺失率三重规则卡口，一票否决高危刷单商户，保障底层流水真实性。


6. **AI 智能风控诊断与离线兜底 (Fallback)**：
集成主流大语言模型 API 端点，自动将枯燥的评分加减分拆解翻译为面向信贷经理的 150 字风控诊断报告；内置离线模板降级能力，断网环境下 100% 稳定运行。

## 🚀 快速上手与运行指南

### 1. 环境准备与依赖安装
建议在 Python 3.9+ 虚拟环境中运行：
```bash
pip install -r requirements.txt
```[cite: 1, 2]

### 2. 执行全套自动化单元测试
一键验证数据清洗网关、防刷单规则、三层路由降级、IV 筛选及评分卡单调性[cite: 1, 2]：
```bash
pytest tests/test_pipeline.py -v
```[cite: 1, 2]
*(预期结果：8 项测试用例全部 PASSED 通过)*

### 3. 一站式端到端真实数据接入示例
```python
import pandas as pd
from src.toolkit.api import CreditToolkit

# 1. 接入外部原始异构流水 (支持淘宝、京东、Olist等任意格式)
raw_orders = pd.DataFrame({
    "seller_id": ["SHOP_001", "SHOP_001", "SHOP_002"],
    "order_purchase_timestamp": ["2026-01-01 10:00:00", "2026-01-02 12:00:00", "2026-01-03 15:00:00"],
    "user_id": ["CUST_A", "CUST_B", "CUST_C"],
    "price": ["$120.50", "$89.00", "250.00"],
    "order_status": ["delivered", "canceled", "delivered"],
    "order_delivered_customer_date": ["2026-01-03", None, "2026-01-05"]
})

# 2. 加载风控评估引擎
toolkit = CreditToolkit.load_pretrained()

# 3. 一键完成清洗、规则审查、特征工程与自适应路由打分
results = toolkit.assess_raw_orders(raw_orders)
print(results[["shop_id", "score", "risk_grade", "model_tier", "风险建议"]])
```[cite: 1, 2]
