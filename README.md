# 《E心助贷》—— 面向电商小微企业的大数据智能风控与融资服务平台

本项目是一个面向电商小微企业的大数据智能风控与融资服务平台，为“工行杯”全国大学生金融科技创新大赛参赛项目。系统旨在利用电商多源真实经营流水替代传统不动产抵押物，破解小微企业“首贷难、无抵押、数据碎片化”痛点，提供透明、合规、自适应的数字化风控全流程解决方案。

---

## 🏗️ 系统总体架构

系统基于“低耦合、高内聚”设计思想，构建五层一体化风控闭环：

```text
［ 外部多源电商交易流水 (淘宝 / 京东 / 跨境电商 Olist 等) ］
                           │
                           ▼
┌────────────────────────────────────────────────────────────┐
│  1. 数据接入与清洗网关 (Data Ingestion & Cleaning Layer)    │
│     - 跨平台字段智能别名映射 (shop_id, amount, status 等)   │
│     - 脏数据清洗、货币符号去噪、时间戳统一与履约状态转化   │
└────────────────────────────────────────────────────────────┘
                           │ 输出标准流水
                           ▼
┌────────────────────────────────────────────────────────────┐
│  2. 前置防刷单规则引擎 (Anomaly Rule Engine)               │
│     - 时间集中度 (>35%)、客户重复度 (>50%)、物流缺失率 (>15%)│
└────────────────────────────────────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────────┐
│  3. 向量化特征工程层 (Feature Engineering Layer)           │
│     - 重构传统 5C 为五大维度共 18 项核心量化特征            │
│     - 基于 Pandas 向量化聚合加速，消除循环耗时              │
└────────────────────────────────────────────────────────────┘
                           │ 输出商户特征矩阵
                           ▼
┌────────────────────────────────────────────────────────────┐
│  4. 核心模型与动态路由层 (Model & Tiered Routing Layer)    │
│     - 三层自适应路由：L1 极简准入 / L2 标准经营 / L3 全维增信 │
│     - 主模型：WOE 等频分箱 + Laplace 平滑 + 标准金融刻度评分卡 │
│     - 参考模型：LightGBM + SHAP 博弈论非线性交叉归因印证   │
│     - IV 动态弱特征剔除机制 (IV >= 0.02)                   │
└────────────────────────────────────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────────┐
│  5. 统一应用与交付层 (Application Layer)                   │
│     - 统一 API 工具包 (CreditToolkit)：支持 assess_raw_orders │
│     - 大语言模型 (LLM) 智能风控报告生成 (含离线规则模板降级) │
│     - Streamlit 交互式大屏：五维雷达图、层级切换与分值归因 │
└────────────────────────────────────────────────────────────┘
